USER NEKO

USER NEKO adalah platform web modern yang berfungsi sebagai portal utama untuk mengakses berbagai layanan, informasi server, komunitas, dan fitur digital lainnya dalam satu tempat.

🌟 Fitur Utama

🏠 Home

- Menampilkan informasi utama dan pengumuman terbaru.
- Banner yang dapat dikustomisasi menggunakan URL gambar.
- Tampilan modern dan responsif.

🛒 Shop

Portal menuju berbagai layanan yang tersedia, seperti:

👑 Neko Store

- Pembelian Rank.
- Informasi produk dan layanan.
- Sistem pembelian yang mudah digunakan.

🎨 Art Shop

- Layanan komisi artwork.
- Berbagai pilihan artist dan gaya gambar.
- Informasi harga dan layanan.

🧭 Server

- Informasi server Minecraft.
- Rules server.
- Informasi survival.
- IP & Port server.
- Status server.

🔐 Authentication

USER NEKO mendukung sistem autentikasi modern:

- Login
- Sign Up
- Google Authentication
- GitHub Authentication
- Logout
- Penyimpanan sesi pengguna

🎨 Tampilan

- Modern UI
- Anime Style
- Responsive Design
- Dark Mode
- Light Mode
- Smooth Animation
- Glassmorphism Effect
- Mobile Friendly

🚀 Cara Menjalankan

1. Download atau clone repository.
2. Buka folder project.
3. Jalankan file "index.html" menggunakan browser.
4. Atau deploy menggunakan:
   - Vercel
   - Netlify
   - GitHub Pages
